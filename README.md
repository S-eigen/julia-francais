# Французский для Моей Юленьки 🤍

Интерактивный одностраничный курс французского
## Что внутри

- **12 недель** структурированных уроков от A1 до B2
- **50 уроков-историй** про Antoine и Juliette по методу «снежного кома»
- **27 уроков грамматики** в виде формул-конструкторов (по Complete French All-in-One)
- **20 тем разговорных конструкторов** (по Collins / Kurbegov / Richards)
- **600+ слов** по темам с тренажёрами
- **Флэш-карточки** для запоминания
- **Тесты** с автопроверкой
- **Тренажёр перевода** с русского на французский
- **Раздел TCF Canada** — стратегии, шаблоны эссе и писем
- **Прогресс сохраняется** в браузере (localStorage)

> **Аудио отключено** — курс полностью текстовый.

## Структура

### 📚 Грамматика (27 уроков)
Каждый урок:
- Простое объяснение по-русски
- Формулы-шаблоны
- Конструктор: подставляй свои слова
- Примеры

Темы: артикли, род, числа, структура предложения, вопросы, восклицания, présent (-er, -ir, -re, неправильные), возвратные глаголы, passé composé, imparfait, plus-que-parfait, futur proche, futur simple, conditionnel, subjonctif, местоимения, относительные местоимения, прилагательные, сравнения, связки, письмо.

### ♥ 50 уроков-историй (Antoine & Juliette)
Метод снежного кома: одна и та же фраза «обрастает» деталями. По 4 уровня в каждом уроке. 5 арок:
1. Знакомство (1-10)
2. Встреча (11-20)
3. Отношения (21-30)
4. Работа и вызовы (31-40)
5. Канада (41-50)

### 🗓️ 12 недель курса
Структурированный план A1 → B2 с тестами и тренажёрами.

## Как использовать локально

1. Открой `index.html` в любом современном браузере (Chrome, Safari, Firefox, Edge)
2. Учись!

Работает офлайн.

## Как опубликовать на GitHub Pages

1. На [github.com](https://github.com) → **New repository** → имя `francais-3-mois`, поставь Public
2. Внутри репо → **Add file → Upload files** → перетащи `index.html` и `README.md`
3. **Settings → Pages** → Source = `main / root` → Save
4. Через минуту откроется по адресу: `https://твой-логин.github.io/francais-3-mois/`

## Рекомендуемый порядок занятий

**Неделя 1-2** — базовые недели курса (1-2) + первые уроки-истории (1-5) + грамматика 1-7
**Неделя 3-6** — недели курса (3-6) + истории (6-25) + грамматика 8-15
**Неделя 7-9** — недели (7-9) + истории (26-40) + грамматика 16-22
**Неделя 10-12** — недели (10-12) + истории (41-50) + грамматика 23-27 + TCF-раздел
